How the solver works

Each element of length h contributes ke = (kA/h)[1 −1; −1 1] and fe = (qAh/2)[1; 1], assembled into a tridiagonal system. Prescribed temperatures are imposed by moving the known column to the right-hand side and replacing the row with the identity (keeps symmetry), then the Thomas algorithm solves in O(N).

Error is measured at element midpoints using FE interpolation, because linear elements on this problem are exact at the nodes. Theory: midpoint error = qh²/(8k), so halving h divides it by 4 (order 2).
